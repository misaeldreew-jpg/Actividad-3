# 📊 Dashboard de Abandono Escolar

Este proyecto presenta un dashboard interactivo desarrollado con Streamlit para analizar el abandono escolar y el desempeño académico de los estudiantes.

## 🚀 Funcionalidades

- Filtros por estado del estudiante
- KPIs principales
- Visualizaciones interactivas:
  - Gráfico de barras
  - Dispersión (correlación)
  - Histograma
  - Boxplot
  - Tendencia

## 📁 Estructura

- app.py → Aplicación principal
- data/dataset.csv → Dataset
- requirements.txt → Dependencias

## ▶️ Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
